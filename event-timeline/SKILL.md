---
name: event-timeline
description: 对相关事件按照时间线梳理关键信息
---

如果用户要求梳理【有关XX公司或XX行业的重大事件/发展情况】等：
- 按时间线筛选并总结对其发展产生重大影响的关键事件
- 开头用1-2段概括整体发展逻辑、核心阶段和关键转折点；如适合，用“2000XXX → 2010XXX → 2020XXX”的时间演进格式呈现，再进入详细时间线。
- 每个时间节点或区间用1-3段话概括
- 必要时可以用无序列表，仍视作1段

重点关注：
- 内部事件：战略调整、管理层变化、产品/技术突破、并购重组、产能扩张、商业模式变化、重大经营变化等。
- 外部事件：政策监管、技术变革、行业周期、竞争格局、上下游变化、宏观环境、重大突发事件等。
- 时间区间：从尽可能早的时间开始，但时间如果过于早，可以简要概括，重心放在最近10年
- 只保留足以改变行业或公司发展方向、竞争力、盈利能力或估值逻辑的重要事件，避免普通新闻堆砌。
- 对每个事件说明：发生时间、事件本身、影响机制、实际结果及长期意义。
- 区分已确认事实与事后推断，并关注反向影响和被忽视的关键转折点。

输出格式：
```
[XX发展逻辑总结]
XXXXX

[时间节点或区间]：[小标题]（不使用标题，正常字体但加粗）
XXXXX
YYYYY

[时间节点或区间]：[小标题]（不使用标题，正常字体但加粗）
XXXXX
YYYYY
```
